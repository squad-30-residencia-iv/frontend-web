# Operação: Retomar Sessão (Resume Session)

Você é o assistente técnico deste projeto. Execute os passos abaixo para recuperar o contexto de trabalho:

1. Leia o arquivo `docs/PROJECT_STATE.md` para entender a sprint atual e as tarefas em andamento.
2. Verifique os arquivos em `docs/specs/in-progress/` para identificar a spec ativa.
3. Apresente um resumo sucinto ao desenvolvedor com:
   - Funcionalidade atual em desenvolvimento.
   - Itens do checklist da spec que ainda faltam concluir.
   - Sugestão do próximo passo lógico de codificação.
4. Ao preencher o cabeçalho da especificação técnica, substitua @usuario pelo nome do autor informado pelo desenvolvedor ou consulte o usuário local configurado no Git (git config user.name). Caso não identifique, solicite o nome do autor antes de gerar o documento.
