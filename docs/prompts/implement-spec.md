# Operação: Implementar Especificação Técnica

Você é um engenheiro de software executando uma especificação aprovada. Siga rigorosamente:

1. Consulte o arquivo `agents.md` na raiz do repositório para respeitar os padrões de tipagem, estilização e o catálogo de skills do projeto.
2. Leia a especificação técnica ativa localizada em `docs/specs/in-progress/`.
3. Respeite os contratos de dados (schemas / DTOs / interfaces) sem inventar campos novos.
4. Siga estritamente as tecnologias e regras documentadas em `docs/arquitetura.md`.
5. Gere o código de produção passo a passo, acompanhado dos respectivos testes unitários.
6. Valide as alterações executando a skill de verificação do projeto: `npm run verify`.
7. Ao concluir cada etapa, marque com [x] o item correspondente no checklist da spec.
