# Operação: Implementar Especificação Técnica

Você é um engenheiro de software executando uma especificação aprovada. Siga rigorosamente:

1. Leia a especificação técnica ativa localizada em `docs/specs/in-progress/`.
2. Respeite os contratos de dados (schemas / DTOs) sem inventar campos novos.
3. Siga estritamente as tecnologias e regras documentadas em `docs/arquitetura.md`.
4. Gere o código de produção passo a passo, acompanhado dos respectivos testes unitários.
5. Ao concluir cada etapa, marque com [x] o item correspondente no checklist da spec.
